## Qué falta y por qué

| Serie no cubierta / incompleta | Período faltante | Motivo |
|---|---|---|
| `inflation_cpi_monthly_linked.csv` (mensual, empalme hasta 1943) | 1943–1996 | No se encontró en GitHub ningún mirror de la serie enlazada Cavallo–Bertolotto ("Filling the Gap in Argentina's Inflation Data", 1943–2016 — solo existe como paper en SSRN, sin repo asociado localizable) ni del "IPC histórico — Empalme de las series base 1943, 1960, 1974 y 1988" que publica `datos.gob.ar` (bloqueado desde este entorno). Si aparece un repo con ese CSV, el archivo tidy destino es `inflation_cpi_monthly_linked.csv`. Parcialmente cubierto a nivel **anual** por `inflation_cpi_annual_linked.csv` (1915–1960, ver abajo) y a nivel **trimestral** desde 2000 por `inflation_cpi_quarterly.csv`. |
| Series 1810–1914 en general (excepto Maddison PIB pc/población y V-Dem) | 1810–1914 | Solo Maddison y V-Dem tienen cobertura tan larga; el resto (precios, cambiario, fiscal) requiere series históricas digitalizadas (CEPAL, Della Paolera & Taylor, IEERAL) que no están en un repo GitHub identificado. `exchange_rate_annual.csv` e `inflation_cpi_annual_linked.csv` (fuente 16) cierran buena parte de 1879–1960, pero no antes. |
| Tipo de cambio anual 1952–1991 | 1952–1991 | `clio_infra_exchange_rates.csv` (fuente 16) tiene valores para Argentina en ese rango, pero son `0.0` (1952–1961) o del orden de `1e-11`–`1e-9` (1962–1974) — un artefacto de escala no resuelto por esa fuente al cruzar las cinco redenominaciones del peso argentino desde 1970. Se excluyeron en vez de reinterpretarlos (ver `SOURCES.md` fuente 16 y `consistency.md` sección 3). `exchange_rate_official_monthly.csv` cubre desde 1992 con dato BCRA fiable; el hueco real que queda es 1952–1991. |
| `gdp_deflator_annual.csv` después de 2006 | 2007–presente | El mirror usado (`ronnywang/worldbank`, snapshot de 2013) no tiene valores para Argentina después de 2006 en este indicador. No se encontró un mirror GitHub más reciente de `NY.GDP.DEFL.KD.ZG`; la API oficial del Banco Mundial está bloqueada desde este entorno. |
| `unemployment.csv` / `poverty.csv` antes de 2003 | 1974–2002 | La serie usada (EPH continua) empieza en 2003. La EPH puntual (ondas mayo/octubre, 1974–2003) está en cuadros XLS de INDEC (`datos.gob.ar`, bloqueado) sin API. Se buscó un mirror GitHub (`matuteiglesias/microdatos-EPH-INDEC`): es un CLI que descarga microdatos EPH **continua** trimestre a trimestre desde el sitio de INDEC (bloqueado desde acá), sin ningún CSV de serie histórica committeado y sin soporte para la EPH puntual pre-2003 — no aporta nada ingestable. No se encontró ningún otro repo con la serie puntual 1974–2003 ya tabulada. |
| `public_debt.csv` desglose por acreedor | todo (solo se cargó el total) | `deuda_total.json` da la serie agregada; el desglose (títulos, préstamos, organismos) está en el Excel MECON, ya con id por componente en el repo, pero no se procesó todo el desglose por presupuesto de tiempo — se puede extraer del mismo `data/series/deuda_*.json` cacheado por DiLoretoT sin red adicional, quedó pendiente. |

### Candidatos encontrados pero no ingeridos (fuera de alcance de esta pasada)

- **`datos-Fundar/valor_agregado_bruto_largo_plazo_argentina`** (GitHub, MIT, cita a
  Ferreres "Dos siglos de economía argentina"): serie anual de Valor Agregado Bruto a
  precios básicos, pesos constantes de 2004, 1895–actualidad. No es ninguno de los cuatro
  indicadores pedidos explícitamente (deflactor, inflación histórica, tipo de cambio
  histórico, desempleo/pobreza), así que no se ingirió esta pasada, pero es un candidato
  directo para extender `gdp_usd.csv`/PIB real hacia atrás en una pasada futura.
- **`forex-centuries`** (fuente 16) trae mucho más de lo que se usó acá: deuda pública
  Clio Infra 1825–2010 (`clio_infra_govt_debt.csv`, % del PIB — unidad distinta a
  `public_debt.csv`, que está en USD millones), clasificaciones de régimen cambiario
  (Ilzetzki-Reinhart-Rogoff), e índices de crisis (Reinhart-Rogoff, en `.xls`). Quedan sin
  usar por alcance/tiempo, no por falta de documentación — podrían ingerirse en una pasada
  futura con el mismo criterio de trust B.

## Cómo completar lo que falta

`scripts/fetch_argentina_local.py` (en la raíz del repo) descarga, desde **tu máquina** (no
desde este entorno, donde esas APIs están bloqueadas), lo que sí tiene un endpoint oficial.
Nota (2026-09-15): `gdp_deflator_annual.csv` (1961–2006) y `exchange_rate_annual.csv`
(1879–1951) ya existen ahora vía mirrors de GitHub (`SOURCES.md` fuentes 16-17); estas
llamadas siguen siendo útiles para **extender** esas dos series con la API oficial
(deflactor 2007+, tipo de cambio 1952–1878 y 1992+ a nivel anual):

```bash
uv run --with requests python scripts/fetch_argentina_local.py --list
uv run --with requests python scripts/fetch_argentina_local.py --series inflation_deflator_annual
uv run --with requests python scripts/fetch_argentina_local.py --series exchange_rate_annual
uv run --with requests python scripts/fetch_argentina_local.py --series public_debt_breakdown
uv run --with requests python scripts/fetch_argentina_local.py --all
```

Cada función escribe en el mismo formato tidy (`date,value,unit,source_id`) que el resto del
directorio. Las funciones que no tienen un endpoint real (EPH puntual pre-2003, tipo de
cambio pre-1992) imprimen qué hace falta descargar a mano y de dónde, en vez de inventar un
resultado.

Fuentes oficiales para lo que queda pendiente (para cargar a mano si `fetch_argentina_local.py`
no alcanza):

- Deflactor del PIB, tipo de cambio oficial FCRF (Banco Mundial): `https://api.worldbank.org/v2/country/ARG/indicator/<code>?format=json`
- EPH puntual histórica (desocupación/pobreza 1974–2003): `https://www.indec.gob.ar/ftp/cuadros/sociedad/`
- Deuda pública por acreedor: `https://www.argentina.gob.ar/sites/default/files/deuda_publica_DD-MM-YYYY.xlsx` (hoja A.2.5)
- Series cambiarias/monetarias BCRA (histórico): `https://api.bcra.gob.ar/estadisticascambiarias/v1.0/` y `https://api.bcra.gob.ar/estadisticas/v4.0/Monetarias`
- Series históricas pre-1943 (precios, cambiario, fiscal): CEPAL "Series históricas", Della
  Paolera & Taylor *Straining at the Anchor* (1810–1935), IEERAL "Estadísticas de la
  evolución económica de Argentina" — ninguna tiene API pública; requiere digitalización manual.
