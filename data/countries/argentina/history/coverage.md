## Corrida real de `fetch_argentina_local.py` (2026-09-15)

Se corrió `uv run --with requests python scripts/fetch_argentina_local.py --all` desde una
sesión remota de Claude Code (no desde la máquina del autor). El proxy de egreso de esa sesión
**también** bloquea los hosts oficiales — no es un cambio de forma de las APIs, es que ninguna
respondió: cada `requests.get` terminó en

```
ProxyError('Unable to connect to proxy', OSError('Tunnel connection failed: 403 Forbidden'))
```

para `api.worldbank.org` (`inflation_deflator_annual`), `api.bcra.gob.ar`
(`exchange_rate_annual`, `bcra_monetarias`), `www.argentina.gob.ar` (`public_debt_breakdown`)
y `datos.gob.ar` (`eph_puntual_1974_2003`). El estado del proxy (`__agentproxy/status`)
registra cada intento como `connect_rejected: gateway answered 403 to CONNECT (policy denial)`.
Hosts probados y también bloqueados: `data.worldbank.org`, `databank.worldbank.org`,
`www.imf.org`, `ourworldindata.org`, `zenodo.org`, `fred.stlouisfed.org`, `huggingface.co`,
`clio-infra.eu`, `api.argentinadatos.com`, `www.economia.gob.ar`, `www.indec.gob.ar`. Solo
responden `github.com`, `raw.githubusercontent.com` y PyPI. Ninguna función del script pudo,
por lo tanto, validarse contra un JSON real: **siguen sin probarse**. Se agregaron dos fetchers
(`bcra_monetarias` para las variables 1, 5, 27 y 160 de la API del BCRA, y
`eph_puntual_1974_2003` para el dataset 343.1 de `datos.gob.ar` vía la API CKAN), escritos
contra la documentación, sin probar.

Lo que sí se pudo cubrir ese día salió de mirrors en GitHub (`SOURCES.md` fuentes 18–21) con
`scripts/build_argentina_history_from_mirrors.py` (reproducible: clonar los dos repos al
commit indicado y correrlo); los cruces están en `consistency.md` secciones 8–13
(`scripts/check_argentina_history_consistency.py`).

## Cómo completar lo que falta

`scripts/fetch_argentina_local.py` (en la raíz del repo) descarga, desde **tu máquina** (no
desde este entorno, donde esas APIs están bloqueadas), lo que sí tiene un endpoint oficial.
Nota (2026-09-15): `gdp_deflator_annual.csv` (1961–2006) y `exchange_rate_annual.csv`
(1879–1951) ya existen ahora vía mirrors de GitHub (`SOURCES.md` fuentes 16-17); estas
llamadas siguen siendo útiles para **extender** esas dos series con la API oficial
(deflactor 2007+, tipo de cambio 1952–1878 y 1992+ a nivel anual):

```bash
uv run --with requests python scripts/fetch_argentina_local.py --list
uv run --with requests python scripts/fetch_argentina_local.py --series inflation_deflator_annual
uv run --with requests python scripts/fetch_argentina_local.py --series exchange_rate_annual
uv run --with requests python scripts/fetch_argentina_local.py --series public_debt_breakdown
uv run --with requests python scripts/fetch_argentina_local.py --series bcra_monetarias
uv run --with requests python scripts/fetch_argentina_local.py --series eph_puntual_1974_2003
uv run --with requests python scripts/fetch_argentina_local.py --all
```

Cada función escribe en el mismo formato tidy (`date,value,unit,source_id`) que el resto del
directorio. Las funciones que no tienen un endpoint real (EPH puntual pre-2003, tipo de
cambio pre-1992) imprimen qué hace falta descargar a mano y de dónde, en vez de inventar un
resultado.

no alcanza):
